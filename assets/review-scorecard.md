# 评分表·一票否决·决策卡（可填写）

配套说明见 `references/scoring-and-veto.md`。**先写事实，再给分；没有事实的分数作废。**

## 0. 先过否决（不过就问，别打分）

> 完整定义与处置见 `references/risk-and-safety.md` 第一节；这里只做勾选。

### V0 硬否决 —— 命中任一，直接出局，不评分
- [ ] 暴力（摔东西、推搡、掐、砸门）
- [ ] 金钱异常（借钱、代付、投资、博彩、要求转账）
- [ ] 欺骗（婚史、子女、年龄、职业、债务）
- [ ] 控制（查手机、限制社交、跟踪）
- [ ] 成瘾（赌博、酗酒、药物）
- [ ] 违法 / 被追债

### V1 条件性否决 —— 先确认，属实即出局
- [ ] 生育意愿相反
- [ ] 定居城市不可协商
- [ ] 冲突时消失超过 3 天且事后不处理
- [ ] 重大决定必须父母拍板且拒绝讨论
- [ ] 婚姻形态期待不同（形婚/丁克/周末夫妻/再婚带娃）
- [ ] 长期异地且无解决时间表

> 确认方式：直接问一次「如果我们结婚，关于 ___ 你怎么想？」躲闪即按否决处理。

## 2. V2 底线分检查（打完分立刻查）

## 7. 自检三问

1. 我的分数里，有几项是拿事实支撑的？没有事实的那几项，是不是我想要它高？
2. 如果对方明天说「不合适」，我是松一口气还是难受？
3. 这张表是帮我做决定，还是帮我拖延决定？
