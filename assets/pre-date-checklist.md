# 出门前 10 分钟检查清单

见面前一天看一遍，出门前再看一遍。

## 信息与安排
- [ ] 时间、地点已确认，双方都回了一条「好」
- [ ] 查过路线，预留了 20 分钟余量
- [ ] 想好了一个附近的备选地点（对方临时换口味/店太吵时用）
- [ ] 把见面地点、对方姓名电话发给了至少一位朋友
- [ ] 约定了「一小时后报平安」

## 话题准备
- [ ] 3 个破冰话题（和现场有关的）
- [ ] 3 个想问的问题（按梯度：信息区 → 兴趣区 → 价值观区）
- [ ] 1 个关于自己的小故事（具体、有细节、能带出性格）
- [ ] 想清楚「哪些话题今天不碰」：收入、前任、彩礼、生育时间表

## 个人状态
- [ ] 衣服干净、合身，比日常正式半档（不要第一次穿新衣服）
- [ ] 头发、指甲、口气、鞋面——四个最容易被注意到的地方
- [ ] 手机静音，桌面不放手机
- [ ] 提前 10 分钟到，先找好位置（斜对坐，不坐正对）
- [ ] 深呼吸三次：目标不是被喜欢，是判断值不值得再见

## 支付与退路
- [ ] 确认支付方式可用（现金/手机都行）
- [ ] 想好结账方式：自己提的见面自己结，或自然 AA
- [ ] 想好离场时间：「一会儿还有个事」——给自己留一个体面的出口

## 结束动作（别忘）
- [ ] 当天或次日发一条消息
- [ ] 24 小时内用 `review-scorecard.md` 打分
- [ ] 给介绍人回话（无论成不成）
