# 相亲日志与月度复盘（可填写）

方法见 `references/learning-loop.md`。原则：**只记事实，不写真名，每次 5 分钟。**

## 一、单次记录（一行一个人）

| 日期 | 代号 | 渠道 | 节点 | 结果 | 分数 | 一句话印象（具体行为） | 否决 | 学到什么 |
|---|---|---|---|---|---|---|---|---|
| | A | 介绍人 | P3 | 继续 | 3.8 | 全程在讲自己的工作，没问我一句 | 无 | 下次见面先看对方问不问 |
| | B | 平台 | P2 | 我停 | — | 约两次都推，说「忙完这阵」 | — | 推两次就停，别等第三次 |
| | | | | | | | | |
| | | | | | | | | |
| | | | | | | | | |

**结果选项**：继续 / 我停 / 对方停 / 自然淡出
**额度提醒**：攒满 5 行再做模式判断，少于 5 行只看个例。

### 附：预测-验证对照（见面前写，见完对照）

| 日期 | 见面前的预测 | 预测最可能踩的雷 | 实际结果 | 对/错 | 错在哪 |
|---|---|---|---|---|---|
| | 想见第二次 | | | | |
| | 不想见 | | | | |
| | 说不准 | | | | |

**命中率 = 对的次数 / 总次数**。低于 50% 说明判断依据有问题，回看是太依赖第一印象，还是过度看重某一项。不写预测，事后只会记得「我早觉得他不行」——那是记忆在替你圆场。

## 二、归因（每 5 行做一次）

- 这 5 次里，卡点大多在第几个节点？＿＿＿
- 主要归因（勾一个）：
  - [ ] 标准问题（条件都对但没感觉 / 反复被同一类人下头）
  - [ ] 渠道问题（介绍人总推同一类人 / 见的人明显不匹配）
  - [ ] 表达问题（对方误解我 / 本人与资料差距大）
  - [ ] 判断问题（前期高分后期崩 / 红旗忽略）
- 依据（写事实，不写感受）：＿＿＿

## 三、模式检查（样本 ≥5 才填）

- [ ] 第四次断崖（前几次好，之后莫名烦躁）
- [ ] 单边消耗（总是我主动，对方一冷我就退）
- [ ] 条件满意、感觉缺席（条件全中，就是不想再见）
- [ ] 以上都不是

对应的调整方向：＿＿＿

## 四、30 天实验卡

```
假设：我 ___，是因为 ___。
动作：接下来 ___ 次见面，我改做 ___。
指标：___ 次里至少有 ___ 次 ___。
期限：30 天 / ___ 次见面，到期复盘。
```

结果（到期填）：
- [ ] 假设成立 → 保留新做法
- [ ] 假设不成立 → 换假设：＿＿＿
- [ ] 数据不够 → 再来一轮（不超过两轮）

## 六、月度复盘四问

1. 这个月最有效的一个动作是什么？（保留它）
2. 最浪费时间的一件事是什么？（砍掉它）
3. 我的标准有没有被现实修正？改了哪一条？
4. 下个月只改哪一个变量？

## 七、季度动作（每 3 个月一次）

- [ ] 重写 `assets/profile-one-pager.md`
- [ ] 复核 12 维权重（这是唯一允许改权重的时机）
- [ ] 匿名化清理三个月前的记录
- [ ] 评估：这个渠道还值得投入吗

## 八、反刍自检

写完上面这些，问一句：**明天我要做的一件具体事是什么？**

- 说得出来 → 这是复盘
- 说不出来 → 这是反刍，先停，去睡觉
