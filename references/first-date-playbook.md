# 首次见面执行手册

首次见面的目标不是「让对方爱上我」，而是**在 90 分钟内判断「值不值得有第二次」，同时让对方有这个意愿**。目标清楚，动作才不会变形。

## 零、见面前：要不要先视频（15–20 分钟）

**目的**：过滤三件事——照片是否真实、说话有没有信息量、气场合不合。成本 15 分钟，能省一次 3 小时的错见面。

**提议话术**（不解释理由、不道歉）：
> 「见面之前要不要先视频聊十分钟？我这周三晚上或周六下午都行。」

**对方拒绝时，看是哪一种**：

| 情况 | 判断 | 怎么办 |
|---|---|---|
| 社恐/不方便，但给了替代（语音、改时间） | 正常 | 接受，按原计划见面 |
| 有顾虑（怕照骗反向、隐私） | 可以理解 | 接受，但把首见定在白天公共场所 |
| 长期拒绝 + 只发照片 + 催着私下见面 | 红旗 | 不单独赴约，参考 `risk-and-safety.md` |

**视频时看什么**：背景是否像正常生活（不是酒店/车内）、他是只输出还是会问、和照片差多少（差距大说明资料失真）。

**20 分钟主动收尾**：「今天先这样，见面再聊。」——把话题留在见面，而不是一次聊完。

**不要**：第一次就要求深夜视频、要求素颜、要求把镜头对准某处。

## 一、定时间与地点

| 项 | 建议 | 原因 |
|---|---|---|
| 时长 | 90–120 分钟 | 太短显得敷衍，太长容易疲劳说错话 |
| 时段 | 下午 3–5 点，或晚饭后 7–9 点 | 下午茶成本低、可进可退；晚饭适合已经聊过几天的 |
| 地点 | 咖啡馆、茶室、公园 + 咖啡、商场里安静的餐厅 | 公共、明亮、交通方便、有退路 |
| 座位 | 直角或斜对坐 | 正对坐像面试，压迫感强 |
| 备选 | 想好一个附近的备选点 | 遇到排队/太吵能立刻切换 |

避免：第一次就选电影院（两小时不能说话）、酒局（失控风险）、对方住处或私人空间、需要长时间车程的郊外。

**为什么是 90–120 分钟**：短于 60 分钟，双方都还在「社交模式」里，说的都是场面话，等于白见；超过两小时进入疲劳区，话变少、看手机、注意力漂移——这些疲劳表现会被对方误读成「不感兴趣」。90 分钟刚好够从寒暄走到真实对话，又停在双方还有话想说的地方。

## 二、出发前的准备（10 分钟能做完）

1. 想好 **3 个话题**、**3 个问题**、**1 个关于自己的故事**。
2. 提前 10 分钟到，先熟悉环境、找好位置。
3. 着装：干净、合身、比日常正式半档。不要新买衣服第一次穿。
4. 手机静音，桌面不放手机。
5. 带现金或确认支付方式（结账时不要卡在付款页面）。
6. 把见面地点和对方基本信息发给一位朋友。

## 三、开场 3 分钟：降低双方紧张

双方都紧张，谁先让对方放松，谁就掌握节奏。

- 先到、起身、微笑、一句「路上还顺利吗」比任何自我介绍都有效。
- 用环境破冰：「这家店我常来，他家的手冲还行，你喝咖啡还是茶？」
- 不要一上来交换简历。前 3 分钟只做一件事：让对方觉得这次见面不会很难受。

## 四、话题梯度：从安全区慢慢往里走

按顺序推进，看对方反应决定停在哪一层。

1. **安全区（0–15 分钟）**：交通、天气、这家店、怎么过来的、今天忙不忙。
2. **信息区（15–40 分钟）**：工作内容（不是收入）、住在哪个区、平时的作息、家人是否同城。
3. **兴趣区（40–70 分钟）**：最近在看的剧/书、周末做什么、旅行去过哪、有什么一直在坚持的事。
4. **价值观区（70–90 分钟，试探性）**：怎么看「两个人都忙的时候家务怎么分」、理想的生活节奏、对未来的大致规划。
5. **敏感区（首次见面原则上不碰）**：收入数字、房产归属、前任细节、生育时间表、彩礼。

**判断依据**：对方回答变短、开始看手机、只回「嗯/还好」，就往回退一层。对方主动追问、身体前倾、开始讲自己的事，才继续往下。

## 五、提问的方式：开放 + 追问

- 封闭问题换开放：「你做什么工作」→「你这份工作最有意思的部分是什么？」
- 追问三连：「然后呢？」「你当时怎么想的？」「最难忘的是哪次？」
- 分享比例控制在 **5:5**。对方说三句，你说两句；不要变成访谈，也不要变成个人演讲。
- 讲自己的时候带细节和情绪，不要只报事实。「我上周第一次做可颂，发面失败了三次」比「我喜欢做饭」有效十倍。

话题库见 `conversation-bank.md`。

## 六、八个高频雷区

1. **查户口式提问**：连续追问收入、房、车、存款。想了解可以问「你现在的工作节奏怎么样」。
2. **过度自我推销**：把自己的条件反复说，会让对方感到被推销。
3. **抱怨前任、父母、公司**：负面情绪会直接降低吸引力。
4. **评价对方外形/年龄**：「你比照片瘦」这类话没有一个是安全的。
5. **大谈前任**：被问到就一句话带过，把话题带回当下。
6. **买单拉扯**：谁提的见面谁买单，或直接 AA。不要在现场争。
7. **迟到超过 10 分钟不说明**：这是最容易致命的小事。
8. **过早承诺**：第一次就说「我觉得我们挺合适的」，会给对方压力。

**这些雷区有同一个机制**：让对方从「回应」变成「被评估」。查户口是被评估，自我推销是逼对方给评价，评价外形是当面打分。人一旦感觉在被评估，就会启动防御——话变少、笑变客气、开始看时间。所以与其背八条禁令，不如记一句：**这句话说完，对方是更容易接话，还是更需要防守？**

## 七、中式相亲的特殊情况

- **介绍人/父母在场**：先照顾长辈，但把主要对话留给你们两人。可以主动说「叔叔阿姨，我们俩聊会儿，您二位歇一下」。
- **为什么必须把第三人请出对话**：介绍人在场时，你们其实在对一个「裁判」说话——双方都会表演得更得体，也都不敢问真问题。把裁判请出对话，不是不尊重，是让这次见面有信息量。
- **对方带闺蜜/朋友**：正常，说明重视安全。多照顾第三人的感受，别只顾着和主角说话。
- **相亲角/父母先见**：明确边界——父母的意见是参考，见面的是你们两个人。
- **异地首次见面**：选在双方中间城市或一方城市的核心区，当天往返，不住对方安排的地方。

## 八、结账与告别

结账：
- 主动结，动作自然，不要问「我来吧？」然后等对方推辞。
- 对方坚持 AA，就接受，别拉扯。可以说「那下次我请」。

告别（决定第二次机会的关键 2 分钟）：
- 明确表达但不越界：「今天聊得挺开心的，我回去想想，改天再约？」
- 不要在现场逼一个「下次什么时候」的答案。
- 不要第一次就拥抱、牵手或送贵重礼物。

## 九、结束后的 24 小时

1. 当天或次日发一条消息（内容见 `followup-and-decision.md`）。
2. 用 `assets/review-scorecard.md` 打分，趁记忆新鲜。
3. 给介绍人回话。
4. 48 小时内发出第二次邀约（如果决定继续）。

## 十、一页纸脚本（可直接发给用户）

```
时间：周六 15:00
地点：__（提前订位，备选 __）
开场：路上顺利吗 + 环境话题
要问的 3 个问题：
  1. 你这份工作最有意思的地方是什么？
  2. 周末一般怎么过？
  3. 有没有什么事是你一直在坚持的？
要讲的我：
  1. 我的工作里我最喜欢的部分
  2. 最近在学/在做的一件事
  3. 我对接下来生活的想法（一句）
不碰：收入、前任、彩礼、生育时间表
结束语：今天聊得挺开心，改天再约
```

## 十一、取消与爽约

### 自己被取消
- **一次**：正常，可能真有事。回一句「没事，你忙，改天」——**把下一次的提议权交给对方**，不追问原因。
- **两次**：要求一个具体替代时间：「这周不方便的话，下周六下午行吗？」不给替代时间 → 降为微信联系人。
- **三次**：停止，不必再问，也不必发告别消息。

### 自己要取消
提前至少 3 小时说明，并给出两个替代时间。不要临开场说「有事」——这是最伤介绍人关系的行为。

### 对方迟到
- 15 分钟内：正常，先点杯水。
- 超过 30 分钟且无消息：留一句「我先走了，你到了告诉我」，然后走。**不等，是给自己的时间定价。**
- 对方来了但毫无歉意：这是优先级信号，记一笔。

### 被放鸽子之后
不追问「你是不是不想来」，不用情绪惩罚（连环消息、阴阳怪气、发朋友圈），只做一件事：**在日志里记一次**（`learning-log.md`）。三次被同一个人放鸽子，就是答案。
