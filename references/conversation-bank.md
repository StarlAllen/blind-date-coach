# 话题与提问库

这份库按「梯度」组织，不是按主题堆句子。用法：先看对方反应再决定往下一层走，不要在第一次见面就把所有好问题用完。

## 一、破冰（前 3 分钟，只求不尴尬）

1. 路上还顺利吗？这边停车/地铁有点绕。
2. 你比我想的到得早，平时也是提前到的人吗？
3. 这家店我朋友推荐的，你喝咖啡还是茶？
4. 今天降温了，你穿这么少不冷吗？
5. 我刚在楼下看到一只特别胖的猫，你养宠物吗？
6. 你公司在附近吗？过来远不远？
7. 我有点选择困难，你帮我看看点哪个？（把选择交给对方，立刻有互动）

破冰原则：**问对方一个 5 秒能答、且和现场有关的问题**。不要上来问职业规划。

## 二、信息区（15–40 分钟，了解基本盘）

问工作内容而不是收入：

- 你这个工作，一天里最忙的是哪个时段？
- 你当初怎么选这个行业的？家里人影响大吗？
- 加班多吗？加班的时候一般几点能走？
- 你在现在这家待多久了？之前做过别的吗？
- 你住哪个区？通勤要多久？

问家庭要轻：

- 你是在这边长大的吗？
- 家里还有兄弟姐妹吗？（不追问婚育、不追问父母收入）
- 父母还在工作吗？离你住得远吗？

**不要问**：具体月薪、存款、房子首付谁出的、父母退休金多少。这些留给介绍人转述，或第三、四次见面后自然提及。

## 三、兴趣区（40–70 分钟，判断生活是否合拍）

- 你周末一般怎么过？有没有固定在做的事？
- 最近有没有看什么剧/书/综艺？推荐一个。
- 你旅行喜欢规划好还是随性走？去过最喜欢的地方是哪？
- 有什么是你坚持了很多年的事？（这个问题的答案最能看出人）
- 你做饭吗？最拿手的一道菜是什么？
- 你运动吗？跑步、健身还是打球？
- 你朋友多吗？平时聚会是什么形式？

追问三连（把一句话变成一段故事）：
1. 「然后呢？」
2. 「你当时怎么想的？」
3. 「最难忘的是哪一次？」

## 四、价值观探测（70 分钟以后，试探性，不要审问）

这类问题的技巧是**先给一个自嘲或中性的引子，再问对方**，避免变成考核。

| 议题 | 可用问法 | 真正想看什么 |
|---|---|---|
| 金钱观 | 「我属于该花就花、不太记账的那种，你呢？」 | 消费习惯、是否有大额负债 |
| 家务分工 | 「我做饭还行，洗碗很痛苦，你介意分工吗？」 | 是否默认家务归一方 |
| 工作强度 | 「我忙起来会连续加班，你能接受另一半这样吗？」 | 对陪伴的期待、是否要人随时在线 |
| 居住城市 | 「你以后想留在这边吗？还是有可能回老家？」 | 长期规划是否一致 |
| 生育 | 「你家里催得急吗？我自己还没想好什么时候。」 | 生育意愿与时间表 |
| 父母距离 | 「你爸妈住得近吗？平时会常回去吗？」 | 婚后与父母的边界 |
| 冲突处理 | 「你生气的时候是会说出来，还是要自己待一会儿？」 | 是否冷战、是否沟通 |
| 前任 | 被问到时一句话带过：「过去的事没什么好讲的，现在比较重要。」 | 不要展开细节，也不要在意对方展开 |

### 听出他在这件事上绕

三个语言标记：

1. **时态和主语模糊**：「之前有过一段」——不说多久、不说怎么结束、不说谁提的。
2. **细节缺失**：故事里没有时间、地点、人名、具体数字，全是「差不多」「反正」。
3. **反问转移**：你问 A，他答 B，再把问题抛回给你。

处理方式：**同一件事换一个角度问第二次**（不是重复问）。一次模糊正常，两次都绕就是「待验证」，记下来别追；第三次还绕，就当作信息本身——他在回避。

第一次见面不拆穿、不逼供。你要的是判断，不是口供。

## 五、冷场急救（10 招）

1. 换场景：「要不要出去走走？」站起来动一下，气氛就变了。
2. 评论环境：店里放的歌、隔壁桌的狗、窗外的雨。
3. 自嘲：「我刚刚是不是问得有点像面试？」
4. 抛选择题：「如果现在能去任何一个地方，你选海边还是山里？」
5. 讲一个刚发生的小事（今天路上的、点单时的）。
6. 让对方教你一件事：手机某个功能、某种咖啡怎么喝。
7. 直接承认：「我们俩好像都有点紧张。」
8. 提到接下来： 「一会儿我还得去趟超市，你呢？」
9. 问一个具体到细节的问题：「你刚说你养猫，它名字怎么来的？」
10. 实在没话：安静喝两口，笑一下，比硬找话题更自然。

## 六、微信节奏

| 场景 | 建议 |
|---|---|
| 加好友后第一句 | 当天发：「我是今天一起喝咖啡的 XX，安全到家了」——给身份、给信息、不索取 |
| 频率 | 一天 1–2 次来回，不要早中晚打卡式问候 |
| 长度 | 和对方字数相当。对方三行，你别写三百字 |
| 内容 | 具体的事 > 空泛关心。「今天路过你说的那家店，果然排队」比「在干嘛」好 |
| 表情 | 对方用就用，对方不用就收着 |
| 语音 | 不熟之前不发长语音 |
| 邀约时机 | 聊到 3–5 个来回、有共同话题时，直接给具体邀约 |
| 已读不回 | 隔一天发一条不带压力的新话题，再没回应就停。不连发、不问「为什么不回」 |
| 连续三天不回 | 视为无兴趣，停止投入，不必发告别消息 |

### 一条消息的认知负荷

「在干嘛」把决策成本全推给对方：要判断怎么回、要不要展开、显得太热情会不会掉价。回复率低往往不是因为你无趣，是因为你给了一个需要对方做决策的问题。

换成给钩子：「刚路过你说的那家店，排了四十分钟队」——对方不用做决策，接一句就行。

判断标准：**你发的这句话，对方要花多少力气才能接住？** 力气越大，回复越慢。

**邀约句式对比**

差： 「有空一起吃饭吗？」（把决定权全推给对方，且没有信息）
好： 「周六下午有空吗？XX 那边新开了家面馆，评价不错，去吃个午饭？」

对方说「最近有点忙」：
- 差： 「那你什么时候有空？」（变成追问）
- 好： 「行，那你忙完这阵子跟我说，我再约。」（给台阶，留出口）

## 七、反例对照（同一件事的两种说法）

| 差 | 好 | 为什么 |
|---|---|---|
| 你一个月挣多少？ | 你现在的工作节奏怎么样？ | 收入是敏感区，节奏是可聊的 |
| 你怎么还单身？ | 你之前有认真谈过吗？ | 前者带评判 |
| 你照片修过吧？ | 你本人比照片精神。 | 前者是质疑，后者是赞美 |
| 我妈说结婚必须有房。 | 我家里对房子比较看重，我自己更在意两个人能不能一起规划。 | 既说明立场，又不是传声筒 |
| 你多大了？ | 你是九几年的？ | 直接问年龄冒犯，问年份体面 |
| 我觉得我们不合适。 | 我这边感觉节奏上不太合，不想耽误你。 | 对事不对人，留体面 |
