# 红线、否决与安全（唯一真相）

**这份文件是 V0/V1 否决清单的唯一来源。** 其他文件只做引用，不复制清单——复制会漂移，而安全相关内容漂移的代价最高。

## 一、V0 硬否决（命中即出局，不评分、不沟通、不解释）

| 类别 | 具体表现 | 为什么必须立即处理 |
|---|---|---|
| 暴力 | 摔东西、推搡、掐、砸门、限制人身自由 | 暴力会升级，且第一次往往以"我太激动了"收场 |
| 金钱 | 借钱、代付、投资、博彩、要求转账、推荐理财平台、让你走流水 | 资金一旦转出基本不可追回，且这是有组织诈骗的标准入口 |
| 欺骗 | 隐瞒婚史、子女、真实年龄、真实职业、债务 | 婚前敢瞒的，婚后会继续瞒，且你已经失去验证的机会 |
| 控制 | 查手机、限制社交、规定穿着、跟踪、要求报备行程 | 控制的本质是"你的选择变少"，不是"他在乎你" |
| 成瘾 | 赌博、酗酒、药物 | 成瘾会持续消耗共同资源，且复发率高 |
| 违法 | 在逃、被追债、涉刑 | 会牵连你的信用与安全 |

处置：**停止接触 → 保留记录 → 告知一位可信的人 → 必要时报警。** 不需要"好好说清楚"，也不需要体面。

## 二、V1 条件性否决（先确认，属实即出局）

| 议题 | 确认方式 | 出局条件 |
|---|---|---|
| 生育 | 「如果我们结婚，关于孩子你怎么想？」 | 一方明确要、一方明确不要 |
| 定居 | 「未来几年你打算留在这边吗？」 | 两个方向都不可协商 |
| 沟通模式 | 观察冲突后 3 天内的行为 | 消失、不处理、下次照旧 |
| 家庭边界 | 「买房/结婚这些事，最后谁拍板？」 | 必须父母决定且拒绝讨论 |
| 婚姻形态 | 直接问 | 形婚、丁克、周末夫妻、再婚带娃等根本错配 |
| 异地 | 「有没有解决时间表？」 | 长期异地且给不出时间 |

V1 的关键是**先确认再否决**。答案躲闪即按否决处理——躲闪本身就是信息。

## 三、诈骗：杀猪盘与婚托

典型路径：**人设完美 → 快速升温 → 引入「副业/投资」→ 小额返利 → 大额套牢**。

识别要点：
- 照片精致且风格统一，视频总是「不方便」
- 认识一周就说「遇到你是缘分」，情绪推进异常快
- 主动谈钱、谈理财、谈「我舅舅在平台内部」
- 让你下载陌生 App、注册陌生网站、扫码充值
- 提现需要「再充一笔解冻」
- 婚托：只在高档餐厅见面、全程引导消费、拒绝二次单独见面

**铁律：不向未见过面的人转账，不点对方发来的投资链接。** 已转账的立即停止联系、保存记录、报警；不要相信「再充一笔就能提现」。

## 四、人身安全

### 前三次见面
- 公共场所，自己往返，不坐对方车回家
- 不透露具体住址、门牌、公司楼层
- 把对方姓名电话和见面地点发给一位朋友，约定报平安时间
- 控制饮酒，杯子不离视线，不接受开封饮料
- 不去对方住处、酒店、私人会所

### 身体边界
- 任何接触以对方主动回应为准；含糊、僵住、转移话题都按「不」处理
- 不因为「都见这么多次了」跳过确认
- 你说停也要被尊重

### 独处与出行
- 第一次长途出行至少交往三个月后，且告知家人行程
- 各自一间房，不接受「订都订了」
- 到陌生城市先确认返程票和紧急联系人

### 数字安全
- 不共享定位、不给密码、不拍不愿被传播的照片
- 「查手机」是红旗，不是爱的证明

## 五、控制与情感操纵

比诈骗更常见，也更难识别：

- **隔离**：「你朋友不看好我们」——逐渐切断你的支持系统
- **贬低**：以「为你好」为名的持续否定，让你怀疑自己的判断
- **反复**：热一阵冷一阵，让你不断猜测自己哪里做错
- **威胁**：用自伤、曝光隐私、分手要挟达成目的
- **越界**：查手机、要求报备、规定穿着和社交

判断标准只有一句：**这段关系里，你的选择变多了还是变少了。**

## 六、金钱边界

- 交往初期不共债、不担保、不代持、不合伙
- 对方开口借钱，先问自己：这段关系承受得起「拒绝」吗
- 共同消费可 AA 或轮流请，但不要形成单方持续付出的默认
- 彩礼、房款走双方家庭明确沟通，不做私下转账

## 七、家庭层面的风险

- 恋爱期就被要求「先怀孕再结婚」「先领证再谈条件」——停下来
- 对方家庭要求你放弃工作、迁居、与原生家庭切断联系——这是重大决策，不是恋爱细节
- 见家长被盘问收入、房产、生育计划，可以礼貌回避，不必当场交代

## 八、怎么提示风险（不越界、不说教）

用户往往在情绪里，直接说「这人是骗子」会被反弹。用五步：

1. **先接住**：「听起来你挺上心的。」
2. **摆事实**：「有三件事我想确认：他提过投资吗？见过面吗？视频过吗？」
3. **给判断**：「这三条同时出现，风险很高。」
4. **给动作**：「先别转钱，也别删记录。你可以约一次线下见面，看他反应。」
5. **留余地**：「也可能是我多虑，你自己判断，但钱这条线别松。」

不替用户做决定，但把风险说清楚。**这是底线，不能为了「不扫兴」省略。**

## 九、紧急处置

- 已转账：停止联系，保存聊天与转账记录，报警（110 / 国家反诈中心 App）
- 被威胁、跟踪、骚扰：保留证据，告知家人朋友，必要时报警并申请人身安全保护令
- 遭遇暴力：先离开现场，去人多的地方，联系可信的人，报警验伤
- 情绪危机：全国心理援助热线 12356，或当地精神卫生中心
