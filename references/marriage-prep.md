# 婚前实务：从订婚到领证

这一段最容易出事，因为谈的从「感情」变成了「利益与责任」。原则两条：

1. **对等**：所有核查双方一起做，不是单方审问。
2. **书面**：重要的安排落到纸上，口头承诺在婚后会自动变形。

> 法律问题以当地民政与司法实践为准；涉及房产、股权、大额财产的，花几千块咨询一次律师，比婚后打几年官司便宜。

## 一、婚前必查清单

| 项目 | 怎么查 | 红旗 |
|---|---|---|
| **婚姻状况** | 结婚登记时民政部门会核验；日常可主动提出「一起去预约登记」 | 推脱、说「户口本在老家」拖几个月 |
| **婚检** | 自愿（2003 年起取消强制），多地有免费项目；建议双方一起做、互看报告 | 拒绝婚检、只让你做、报告不给看 |
| **征信** | 本人持身份证到人行或银行打个人信用报告；双方交换看 | 有逾期不解释、拒绝查询、「查这个是不信任我」 |
| **涉诉与被执行** | 中国裁判文书网（姓名检索）、中国执行信息公开网 | 有民间借贷纠纷、被列为被执行人 |
| **房产** | 房产证、不动产登记信息（本人可查自身名下）；看抵押、共有人、贷款余额 | 只说「有房」不给看证、房子在父母名下但由他还贷 |
| **债务** | 直接问 + 看征信 + 问家庭负债（父母借款、担保） | 「就一点网贷」但不说金额；替家人担保 |
| **健康** | 慢性病、精神病史、成瘾史、家族遗传病、生育相关检查 | 隐瞒服药史、家族病史一句不提 |
| **无犯罪记录** | 本人可向户籍地派出所申请开具 | 拒绝开具、说「没必要」 |
| **学历与职业** | 学信网；社保缴纳记录 | 学历说法反复、职业与收入明显不符 |

**为什么要查**：婚姻是唯一一份你不知道对方资产负债表的合伙协议。查不是不信任，是尽职调查；**双方对等查**，你也把自己的给对方看。

## 二、彩礼：习俗、法律与谈法

### 法律性质
彩礼在法律上通常被认定为**附条件的赠与**（以缔结婚姻为目的）。

### 可以要求返还的三种法定情形
1. 双方**未办理结婚登记**；
2. 已登记但**确未共同生活**（需以离婚为条件）；
3. 婚前给付并**导致给付人生活困难**（需以离婚为条件）。

### 留证据（很重要）
- 转账走银行并备注「彩礼」，不要全给现金；
- 有媒人/介绍人见证，最好有书面清单（金额、首饰、其他财物）；
- 双方家庭谈的时候，微信文字确认一遍。

### 谈法
- 双方父母在场，先各自说底线，再找方案；
- 可交换项：金额、首饰、婚礼规模、房车、婚后居住；
- 不通过介绍人传话——转述必然失真；
- **坑**：口头答应后临时加价、现金无凭证、拿「别人家都这样」施压、谈崩了还拖着不退。

## 三、房产与出资

| 情形 | 要注意的 |
|---|---|
| 婚前一方全款 | 属婚前个人财产；加名等于部分赠与，要办变更登记 |
| 婚前首付 + 婚后共同还贷 | 房本写谁、还贷怎么算、离婚时补偿怎么算，提前说清并留还款记录 |
| 双方共同出资 | 按份共有还是共同共有？份额写进合同 |
| 父母出资 | 是**赠与**还是**借款**？最好书面写明；婚后父母出资默认是对夫妻双方的赠与，除非明确只给一方 |

**提醒**：加名、份额、贷款人变更都涉及产权与税费，别只听中介和亲戚，走正规流程。

## 四、婚前财产协议：什么时候需要

- 一方有公司/股权、大额婚前财产
- 再婚、带娃
- 双方经济差距大
- 一方有较大债务或家庭负担

**怎么开口**（不伤感情的说法）：
> 「我不是防你，是想把话说在前面——以后为钱吵架，比现在谈清楚难多了。我们把各自的、共同的写明白，反而省事。」

**内容要点**：婚前财产清单、婚后收入归属、债务承担、房产份额、离婚时的处理方式。
**形式**：双方自愿、书面、可公证；被胁迫或显失公平的协议无效。

## 五、婚礼与两家对接

- **预算与出资**：总额、谁出多少、超支怎么办；不要为婚礼借钱。
- **份子钱归属**：谁收谁还礼，提前说清。
- **形式分歧**：办酒 / 旅行结婚 / 小型仪式；桌数、习俗、回礼。
- **决策权**：新人是决策者，父母是支持者。两家意见冲突时，**由你们两个人先统一口径**，再各自对自己父母说。
- **坑**：婚礼筹备期的争吵往往暴露真实分工与边界——别用「办完就好了」糊过去。

## 六、婚后安排（婚前就要谈，别等住进去）

| 议题 | 必须定下来的 |
|---|---|
| 住哪 | 与父母同住 / 就近 / 独立；房子写谁名 |
| 钱怎么管 | AA / 共同账户 / 一方管钱；各自留多少自由支配 |
| 家务与育儿 | 谁做什么、能不能外包、老人帮带的边界 |
| 生育 | 要不要、什么时候、几个、谁带、月嫂/老人、教育投入 |
| 赡养 | 双方父母的经济支持、生病照护、接到身边住 |
| 节日与亲戚 | 回谁家、频率、亲戚借钱怎么拒 |

## 七、领证与流程

材料（身份证、户口本、照片）、提前预约、婚检、领证后户口迁移、社保公积金、保险受益人变更。

## 八、婚前最后一次「对齐会议」

领证前找一次不被打扰的时间，把这 12 个问题过一遍，答不上来的先别领证：

1. 房子写谁名、贷款谁还、父母出资算什么？
2. 各自的债务有多少？有没有替人担保？
3. 婚后钱怎么管？每月给父母多少？
4. 和父母住吗？他们能不能随时来？
5. 要不要孩子？什么时候？谁带？
6. 家务怎么分？能不能请人做？
7. 一方工作调动去外地，怎么办？
8. 双方父母生病，谁照顾、出多少钱？
9. 过年回谁家？轮流还是各回各家？
10. 对方有没有你不知道的健康问题或家族病史？
11. 如果三年没孩子，怎么面对双方家庭？
12. 真过不下去，财产怎么分、孩子怎么办？

## 九、危险信号（婚前版）

- 临时加价、临时改条件
- 拒绝婚检、拒绝披露债务、拒绝给看房产证
- 催着领证、不给你思考时间（「日子都定了」）
- 父母全程主导，本人不表态
- 要求「先怀孕再结婚」
- 一提协议就翻脸、说你算计
